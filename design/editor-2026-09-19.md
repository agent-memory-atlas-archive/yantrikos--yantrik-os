# Native Editor workbench — 19 September 2026

Editor is now a working native application. Files, Open With, and the launcher route to the same window. Repeated launches forward the file through its control socket; an OS file lock prevents duplicate editor processes. Existing paths select their existing tab.

## Interface and editing

- Shared shell typography and light/dark tokens, a quiet tab strip, a path row, native selection, synchronized line numbers, scrolling, and a compact status bar.
- Eight independent documents; dirty indicators and explicit Save / Discard / Cancel before closing a modified tab or window.
- Ctrl+O, Ctrl+S, Ctrl+Shift+S, Ctrl+N/T, Ctrl+W, Ctrl+Tab, Ctrl+F/H, Ctrl+G, Ctrl+Z, Ctrl+Shift+Z/Y, F3/Shift+F3, and font zoom with Ctrl+plus/minus.
- Find uses Unicode-aware case-insensitive matching with original UTF-8 offsets. Replace All checks output size before allocating and builds the result in one pass. Go To Line moves the actual caret and reveals it.
- Per-document undo/redo stores up to 64 edit steps and 2 MiB of snapshots. Undo history survives tab switches and saves. Individual physical keystrokes are separate edit steps.
- Optional lightweight lexical colors for comments, strings, and common keywords in recognized source types. Coloring stops above 64 KiB and leaves tabbed/non-ASCII lines plain; editing remains fully Unicode. It is not a language server or a full syntax parser.

## Files and recovery

Document I/O runs on a serialized worker. Editing and tab transitions pause while an open/save is in progress, so a completion cannot overwrite newer edits or another tab. UTF-8 text is bounded at 1 MiB and 20,000 newline separators per document. Invalid UTF-8, binary control characters, devices, pipes, and larger inputs are rejected without replacing the current buffer.

Save writes a private temporary file beside the target, syncs it, then atomically publishes it and syncs the directory. Save As refuses existing paths. Save checks the original content for external changes and refuses hard-linked or read-only originals. Failures leave the draft dirty and visibly report the error. Basic Unix permissions are preserved; ACLs, xattrs, and ownership are not a metadata-preservation contract. The pre-save conflict check is not an atomic compare-and-swap against non-cooperating external writers.

Drafts are checkpointed after 750 ms without an edit to `$XDG_STATE_HOME/yantrik/editor/drafts.json` (default `~/.local/state`). The directory is private and the file is mode 0600. Draft recovery never writes the original document. After a crash the recovered tabs remain dirty for review. A clean exit serializes and flushes the final state after queued writes. An unreadable recovery file is preserved and further checkpoint failures are shown. The last debounce interval can be lost on abrupt power/process failure.

When the session explicitly forces software OpenGL and has not selected a renderer, Editor uses Slint’s software renderer directly. Hardware sessions and explicit renderer choices are preserved. No document timer runs while idle. The underlying Slint TextInput still has its own edit bookkeeping, so the application does not claim a strict lifetime process-memory ceiling. ## Shell integration

Files' default text routing and Open With now start native Editor. Launcher entries use canonical app IDs, so Editor's taskbar title matches its real window title. Compositor discovery, cached for nine seconds, is merged with the launch registry: Terminal and Notes remain in the taskbar after a shell restart and a subsequent Editor launch. This change does not redesign the taskbar's pre-existing first-item active styling.

The old embedded screen remains for legacy shell automation. It no longer silently autosaves, no longer drops a modified tab on close or at the tab limit, and does not report a failed save as successful. Legacy search uses exact matching rather than unsafe offsets into a lowercased string. Native Editor is the maintained user-facing editor and recovery implementation.
